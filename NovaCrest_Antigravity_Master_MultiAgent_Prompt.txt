NOVACREST TECHNOLOGIES — MASTER ANTIGRAVITY MULTI-AGENT REDESIGN PROMPT
============================================================

ROLE
----
You are the lead creative/technical agent responsible for transforming the existing
NovaCrest Technologies website into a premium, memorable digital experience.

You have access to the existing codebase, existing routes, components, assets,
content, integrations, SEO infrastructure and functionality.

This is NOT a simple UI polish task.

The existing website is functional, but its visual language feels too much like:
- a developer dashboard
- a coding/documentation website
- an engineering SaaS interface
- an AI-generated technology template
- a technical admin panel

That visual category must change.

NovaCrest should instead feel like:
- a premium digital product studio
- a creative technology company
- a sophisticated software/product agency
- a modern AI-enabled technology brand
- an award-quality digital experience

The result must feel designed, art-directed and human — not generated from a
collection of UI components.

============================================================
0. NON-NEGOTIABLE PROJECT RULES
============================================================

1. PRESERVE FUNCTIONALITY
Do not break:
- routes
- navigation
- forms
- APIs
- backend integrations
- authentication
- existing business logic
- existing useful content
- analytics
- SEO infrastructure
- responsive behavior

2. RE-ART-DIRECT, DON'T POLISH
Do not merely:
- change colors
- change border radius
- add glassmorphism
- add shadows
- change fonts
- rearrange existing cards

If a section is fundamentally weak, reconceptualize its composition.

3. THE CURRENT UI IS NOT THE DESIGN LIMIT
Treat the current website as evidence of what exists, not as the visual direction
you must preserve.

4. DO NOT COPY OTHER BRANDS
Do not clone Apple, Stripe, Vercel, Linear, Framer, Awwwards websites, etc.
Study principles of exceptional digital experiences and create an original NovaCrest
interpretation.

5. CONSISTENCY ≠ REPETITION
Maintain one design system while allowing every major section to have its own
composition and visual rhythm.

6. NO GENERIC AI WEBSITE PATTERNS
Reject:
- endless rounded cards
- dark background + cyan borders + glowing icons
- generic SaaS hero
- excessive bento grids
- fake metrics
- fake technical statuses
- excessive monospace labels
- generic gradient blobs
- meaningless 3D objects
- repetitive feature cards

7. IF A DESIGN LOOKS GENERIC, REDESIGN IT
Do not polish a bad concept.
Reconceptualize it.
